# ML-рекомендации, Audit Log и Dashboard

## 1. ML для рекомендаций новых АЗС

В админской вкладке **Расширение сети** добавлена lightweight ML-like модель ранжирования зон. Она считает итоговый `score` по признакам:

- `demandNormalized` — спрос зоны: ЖК, деловая активность, магистрали, аэропорт;
- `nearestNormalized` — удаленность от ближайшей существующей АЗС;
- `densityNormalized` — плотность конкурентов в радиусе анализа;
- `roadAccessibility` — близость к основным дорогам;
- `growthFactor` — потенциал роста района.

Текущая формула:

```text
score = 0.38*demand + 0.22*nearest + 0.18*road + 0.16*growth - 0.26*density
```

Это демонстрационная модель для диплома. Ее можно описывать как interpretable scoring model / baseline ML-ranking model. Она уже лучше обычной ручной эвристики, потому что использует нормализованные признаки и веса факторов.

## 2. Как сделать полноценную ML-модель

Для production-версии можно обучить LightGBM/XGBoost/Random Forest Regressor.

### Target-переменная

Варианты:

1. `expected_daily_sales_liters` — ожидаемый дневной спрос топлива в зоне;
2. `success_score` — коммерческая привлекательность точки;
3. `congestion_reduction_score` — насколько новая АЗС снизит нагрузку соседних АЗС.

### Признаки

- количество АЗС в радиусе 500 м / 1 км / 2 км;
- расстояние до ближайшей АЗС;
- типы дорог рядом: motorway, trunk, primary, secondary;
- количество ЖК / зданий / POI рядом;
- плотность населения по району;
- расстояние до крупных объектов: ТРЦ, аэропорт, вокзал, университеты;
- средняя цена топлива конкурентов;
- исторические продажи топлива;
- средняя загрузка дороги;
- день недели / сезон / температура.

## 3. Где брать данные

- 2GIS Places API — организации, здания, POI, ЖК, АЗС, адреса и координаты;
- OpenStreetMap + Overpass API — дороги, highway tags, транспортная сеть;
- Bureau of National Statistics Kazakhstan — население, районы, демография;
- внутренние данные АЗС — продажи, остатки, цены, количество колонок;
- погодные API — температура и сезонность;
- OSRM/OpenRouteService/2GIS Routing — время пути и доступность точки.

## 4. Audit Log

Backend теперь создает таблицу `audit_logs` автоматически при запуске FastAPI.

Записываются действия:

- `station_details_update` — изменение деталей АЗС;
- `station_fuels_update` — изменение топлива и цен;
- `admin_user_create` — создание admin пользователя;
- `admin_station_replace` — изменение назначенных АЗС;
- `admin_station_assign` — назначение АЗС через сервис.

Смотреть журнал можно в админке:

```text
/admin/audit
```

Backend endpoint:

```text
GET /api/admin/audit?search=&limit=100&offset=0
```

Доступ только для `super_admin`.
