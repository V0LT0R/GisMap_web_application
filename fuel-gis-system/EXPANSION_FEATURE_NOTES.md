# Expansion / Размещение новых АЗС

Добавлена вкладка админки `/admin/expansion` — «Расширение сети».

## Что реализовано

- карта Астаны в админке;
- отображение АЗС, доступных текущему admin/super_admin через `/api/stations/my`;
- отображение основных дорожных осей;
- отображение потенциальных зон размещения новой АЗС;
- учет плотности уже существующих АЗС рядом с каждой зоной;
- учет крупных жилых зон, новых районов и магистральных потоков;
- возможность добавить выбранную рекомендованную зону как точку «Скоро появится»;
- возможность вручную поставить точку новой АЗС кликом по карте;
- эти будущие точки также отображаются на основной публичной карте.

## Как работает текущий алгоритм

Сейчас используется эвристическая скоринговая модель:

`score = спрос зоны + удаленность от ближайшей АЗС + дорожный бонус - штраф за плотность существующих АЗС`

Факторы:

- крупные ЖК / плотные жилые зоны;
- новые районы города;
- основные дороги и выездные магистрали;
- расстояние до ближайшей АЗС;
- количество АЗС в радиусе анализа.

Это хорошо подходит для дипломной демонстрации: алгоритм объяснимый, визуальный и не требует отдельной обученной ML-модели.

## Как улучшить до ML-модели

Для настоящей модели можно собрать датасет по ячейкам города 500×500 м или 1×1 км.

Признаки:

- количество ЖК в радиусе 500 м / 1 км;
- количество квартир или оценка населения;
- расстояние до ближайшей АЗС;
- количество АЗС в радиусе 1–2 км;
- близость к магистралям;
- POI: ТРЦ, офисы, университеты, вокзал, аэропорт;
- средний автомобильный поток по дороге;
- продажи топлива по существующим АЗС;
- загруженность/очереди;
- средние цены конкурентов;
- доступность участка.

Целевая переменная:

- прогнозный спрос топлива;
- ожидаемая загруженность;
- класс пригодности зоны: low / medium / high.

Модели:

- Random Forest Regressor / Classifier;
- XGBoost / LightGBM;
- CatBoost, если много категориальных признаков;
- простая нейросеть только при большом объеме данных.

Источники данных:

- 2GIS API: АЗС, ЖК, POI, дороги;
- OpenStreetMap / Overpass: дороги, landuse, POI;
- данные АЗС из вашей системы: цены, остатки, продажи, загруженность;
- статистика населения по районам;
- внутренние CSV-выгрузки по топливу.
