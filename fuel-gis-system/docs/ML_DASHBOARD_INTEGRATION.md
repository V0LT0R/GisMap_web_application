# ML dashboard integration

В проект добавлен frontend-модуль `frontend/src/lib/analytics/mlFuelForecast.ts`.

Он использует результаты обученной модели из пакета `ml_fuel_training_package`:

- `R2 = 0.8369`
- `MAPE = 17.4014%`
- `MAE = 38.8167 L`
- `RMSE = 56.9654 L`

Артефакты модели сохранены в:

`backend/ml_artifacts/fuel_demand/`

Сейчас dashboard использует ML-прогноз как базовый 24-часовой профиль расхода топлива и масштабирует его под конкретные АЗС с учётом:

- расположения относительно зон Астаны;
- близости к крупным ЖК и основным дорогам;
- количества колонок;
- доступности видов топлива;
- прогнозной загруженности.

На общей карте для каждой АЗС теперь отображается рекомендуемое время посещения. Оно не одинаковое для всех станций: станции рядом с ЖК, магистралями и зонами роста получают более ранние/длинные пиковые периоды, поэтому рекомендация отличается от спокойных районов.

2GIS traffic API напрямую не подключался, потому что публичный простой доступ к текущему трафику обычно требует отдельного ключа/доступа. Архитектурно вместо него можно добавить `traffic_score` в `mlFuelForecast.ts` или получать этот признак через backend endpoint.
